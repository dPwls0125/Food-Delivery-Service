ℹ DISPATCH LOGIC
• SINGLE: 가장 가까운 READY 라이더 자동 배정
• BUNDLE: 이미 DISPATCHED 라이더와 묶음 시도

• 라이더 없을 시: 503 반환

📡 API ENDPOINTS
POST /orders — 주문 생성

POST /deliveries/{id}/dispatch — 배차 요청

GET /orders/{id}/notifications/subscribe — 고객 SSE
GET /routes/me/current-route — 현재 경로
ℹ DEMO GUIDE
① CUSTOMER 탭: 주문 생성 → 결제
② DISPATCH 탭: 배차 요청 (POST /deliveries/{id}/dispatch)
③ RIDER 탭: SSE 구독 → 배차 알림 수신 확인
④ RIDER 탭: 위치 업데이트로 이동 시뮬레이션
⑤ CUSTOMER 탭: SSE 구독 → 근접 도착 알림 수신
⑥ RIDER 탭: PICKED_UP → DELIVERED 상태 업데이트
* 서버 실행 후 사용: ./gradlew bootRun
* CORS 에러 시 서버 CORS 설정 확인
